# Parking Management Angular Conversion

Ez az Angular-verzió a feltöltött role-based dashboard front-end újraírt változata.

## Funkciók
- mock bejelentkezés 3 szerepkörrel: user / officer / admin
- role based routing és guardok
- dashboard oldal szerepkör alapján
- vehicles, parking, tickets, fines, zones oldalak
- localStorage alapú mintaadat-kezelés
- reszponzív sidebar layout

## Demo fiókok
- `user@demo.com`
- `officer@demo.com`
- `admin@demo.com`
- jelszó: bármi

## Indítás
```bash
npm install
npm start
```

## Build
```bash
npm run build
```
